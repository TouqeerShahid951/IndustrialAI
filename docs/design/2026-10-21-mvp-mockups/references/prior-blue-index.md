# Industrial AI — refined option 2 mockups

Fourteen screen/state mockups for the complete upload-and-review MVP. The user chose the dark Evidence Focus direction and requested Apple-inspired refinement before implementation. All five capabilities remain in scope.

**Start here:** [Design system](/Users/tabbasi/Downloads/IndustrialAI/docs/design/2026-10-21-mvp-mockups/design-system.md) · [Interaction specification](/Users/tabbasi/Downloads/IndustrialAI/docs/design/2026-10-21-mvp-mockups/interaction-spec.md)

## How to read this set

- `06-incident-review.png` is the shared desktop visual reference. Other capability views reuse its shell and controls.
- `09-mobile-review.png` shows frame-based review without assuming remote video playback is available.
- Source images come from the existing public research footage. All boxes, track IDs, review records and progress values in the mockups are illustrative. Generated mockup imagery is not evidence footage and must not enter a training/benchmark dataset.
- Mockup labels and proportions are a design reference; the companion specifications resolve small generated-raster inconsistencies. Actual interactions and accessibility require verification during the build.
